# Volatility Forecasting: GARCH vs LSTM

This project forecasts five-trading-day realized volatility of the S&P 500 using GARCH-family models and an LSTM, then compares them using RMSE, MAE and QLIKE.

## First steps

1. Read `IMPLEMENTATION_PLAN.md`.
2. Complete T0 setup.
3. Complete T1 data preparation and metrics.
4. Complete T2 and T3 GARCH models and forecasts.
5. Complete T4 Streamlit dashboard.
6. Coordinate with Anvi for LSTM, evaluation, notebook and final integration.

Do not claim results until the scripts have run and produced real output files.
